# FAQ

## Is KAIROS-ORBIT useful with only one chat history?

Yes. That is KAIROS-ORBIT Lite. It can analyze conversation habits and trends from a single source.

## What does Lite miss?

Lite cannot strongly prove that work shipped, tests passed, tools ran, or outputs were used. It should report lower confidence for Instrumented Execution and Outcome Integration.

## Does the framework require coding-agent logs?

No. Coding-agent logs improve Full-mode analysis, but they are not required for Lite analysis.

## Can this compare two people?

Only with caution. The data coverage, task mix, source mix, and time windows need to be similar. Otherwise the comparison may mostly measure data availability.

## Does ORBIT judge whether someone is polite?

No. ORBIT measures whether observable interaction patterns help or hurt the
workflow: correction style, repair quality, affect-friction markers,
directiveness, responsibility language, and next-step control. It should not
moralize direct communication or reward politeness for its own sake.

## Can a terse command be fluent?

Yes. Directness can be appropriate, and terse high-density commands can be
highly fluent when they contain clear scope, constraints, evidence, or next
steps. The negative pattern is friction or contempt plus no evidence or repair
path.

## Can frustration be productive?

Sometimes. A frustrated correction paired with evidence, verification, and a clear next step can be productive repair. The framework should distinguish frustration from contempt and distinguish venting from recovery.

## Is this validated?

Not yet. The framework includes a validation protocol and should be treated as exploratory until human annotation and criterion validation are complete.

## Should raw transcripts be published?

No. Use synthetic examples or aggregate results unless every affected person has explicitly consented.
